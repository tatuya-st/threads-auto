# Threads 自動投稿（ガジェ好きT.S｜物欲会議）

楽天ROOMに投稿した商品から3件を選び、画像つきのまとめ投稿をThreadsに自動で出します。

- queue/ … 投稿予定（Claudeが毎日2回用意）
- images/ … 投稿画像（自動で作成）
- state/ … 投稿済みの記録（二重投稿の防止）・暗号化したトークン
- index.html … 成績表（GitHub Pages: https://tatuya-st.github.io/threads-auto/）
- 毎日 19:23 コメント確認 → 夜にルイが仕分け：★は queue/replies/ に置いて自動で返信（結果は state/replied/）、本人が返すものは下書きを state/drafts.json → Issue でスマホに届く
- リンク返信は約1日1回まで（20時間あける）。リンクはレイと分け合い、奇数日＝ルイ・偶数日＝レイ（日本時間）。偶数日のルイの投稿はプロフィール案内だけ（state/link_off.json に日付を入れると臨時でお休み）。商品つき投稿は必ずPR表記。同じ商品（商品コード・商品名）は二度と出さない
- 文章は人間らしく：決まり文句・宣伝っぽい行・👇の連発は使わない。友だちに話しかける短い言葉で
- 投稿時間は tools/timing.py が閲覧数から選ぶ（用意から0〜80分後）。失敗は Issue（alert）で通知
- 商品1件の画像はレイ風（2026-11-03〜）：写真が主役で上の約3分の2を占め、下は短い一言・価格・商品名だけの広告デザイン（tools/render.py の render_scene）。主役が商品の活きる場面を演じるイラストつき（ハロウィン時期10/15〜10/31だけ物欲おばけ、それ以外は財布欠席くんのぬいぐるみの場面写真 assets/scenes/、吹き出しのひと言は毎回入れ替え）（tools/scenes.py）。誰が見ても絵だとわかるタッチで「※イラストはイメージです」を入れる。実物写真のふりをした画像は作らない
- 夜の商品投稿は、レイが直した画像が届いてから出す（2026-11-03〜）。build_queue.py が夜の商品投稿を自動で画像待ち（hold）にし、ルイの見本画像だけ先に作る。その見本をマスターに画像だけ送り、マスターがレイに直してもらった画像を受け取ったら tools/apply_photo.py で入れて投稿する（届かない夜は商品投稿をお休み）。リンクの日（奇数日）は朝の会話投稿の返信にもROOMのリンクが付く
- マスターが前もって送った場面画像は assets/photos/ready/<商品コード>.jpg、投稿画像まるごとは <商品コード>_full.png に置く（まるごとが優先）。その商品の投稿を作るとき自動で使われるので、画像待ち（hold）にしない
- レイ（別のAI）との分担は docs/rei.md。書き込み上限（429）が出たら、その日のルイの投稿・返信は止めて通知（state/limit.json）。レイの投稿は state/rei_posts.json に自動で記録し、話題・商品かぶりを避ける
