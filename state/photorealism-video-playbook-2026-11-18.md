## 結論のワークフロー（世界の作り手の共通形）

1. 静止画を先に確定する（正本の顔＋参照パック＋完成した1枚）。動画はその静止画を動かす形（image-to-video）が基本。テキストだけで動画を作らない。生成した動画を次の参照に使い回さない（劣化が連鎖する）
2. 1クリップ＝簡単な動作1つ＋カメラの動き1つ。生成は3〜8秒、使うのは一番良い2〜5秒。5〜15秒の完成形はクリップの編集で作る
3. 映画でなくスマホで撮る：撮影デバイスを名指しして、その機材の癖（オートフォーカスの迷い、露出の変動、手ブレの微振動、深い被写界深度）ごと再現する。仕上げは後処理で寄せる

## 指示文

- 画像から動画を作る時の指示は「動きだけ」を書く（被写体の説明を繰り返さない）：対象＋動作＋カメラ＋リズム＋変えないもの、の順
- 肌は静止画編と同じ：毛穴・産毛・左右の非対称を言葉で。「8K」「超リアル」等の盛り言葉は使わない
- フレームレートは作品内で統一：映画寄り24fps、スマホ寄り30fps

## 動きの安全圏（ここを外さない）

- 安全：微細な動き（髪・まばたき・小さな表情）／座ったまま・立ったままの存在感／商品を両手で持つ／ゆっくり真っ直ぐ歩く（後ろ・横から）
- 危険：座る・立つを1テイクで／細かい手作業の持続（化粧を塗る寄りの絵、ボタン、タイピング）／2人の接触／長い全身テイク
- 対策：結果の姿勢から始める（荷重がかかった状態を1フレーム目に）／力む所でカットする／最初と最後のフレームを指定して挟む
- 化粧の場面は「塗る所」は見せず、結果の静止画＋前後のカットでつなぐ

## 顔の一貫性（正直な限界）

- 参照パック方式（顔の複数枚＋人物の確定記述を固定文で毎回使う）が最良。短い・動きの小さいクリップでは保てる。カットをまたぐ時は毎回、正本で立て直す
- 大きな表情と極端な角度で先に崩れる。どの道具でも同一性の保証はない
- 三姉妹の顔が動画で保てないという既存の結論（2026-11-16）と調査結果は一致する。動画の人物は引き続きオリジナル女性キャラで作り、ここで得た動き・スマホ感・仕上げの技術をそちらに適用する

## スマホ動画の癖（名指しする語彙）

- フロントカメラの自撮り動画：目線より少し下、頭上の余白が揺れる、日陰から日向で露出が変わる。ボケ（ポートレート動画）とジンバルの滑らかさは付けない
- 注意：モデルによっては「スマホで撮影」と書くと画面の中にスマホ自体が描かれることがある。その場合は後処理で寄せる

## 仕上げ（後処理の順序）

編集→フレームレート統一→スマホ寄りの色味→時間方向の粒状感（つぶがチラつく形。静止画のノイズとは別）→少しだけ柔らかく（0.3〜0.8px相当）→720pへ縮小＋二重圧縮→微振動を足す（手ブレ補正はしない）→環境音とBGMはCapCut等で
- 実物のカット（本物の商品・手の実写）を1つ混ぜると全体の信憑性が上がる

## 検品（動画のNG判定）

- 1フレーム目を飛ばして見る／通常速度と0.5倍速の両方で見る／最後の3フレームを必ず見る／固い失敗が1つでもあれば、そのクリップは捨てる
- 見る点：顔の同一性、目とキャッチライト、歯、髪の生え際、手（全フレームで指5本）、商品ラベルの安定、背景の直線、物理（重さ・接触）、肌の質感と動きの拍子

## 道具の位置づけ（2026年後半の海外評価、変動が速いので断定しない）

- Veo系：実写感と音に強い。材料（参照）は最大3点まで
- Kling系：人の動きとモーションコントロールに強い。顔の参照は顔専用で向きを合わせる決まり
- Seedance系：複数カット・複数参照に強い
- Runway系：制御と編集に強い
- Soraは終了済み（2026年にアプリ・APIとも閉鎖の報）。前提にしない

## 上級編（2026-11-18夜、全世界調査で追加。正本レポートは research_notes/photorealism-advanced-2026-11-18-20261118-1142/report.md）
### バレ要素12項目（対策の核は後処理でなく設計）
顔ドリフト／テクスチャの沸騰／光のちらつき／背景の呼吸／文字崩壊／手と装身具／歩行の無重力／髪と布の物理（二次運動の欠如）／瞬きの等間隔と視線のサッカード欠如とキャッチライト凍結／リップシンク（破裂音で唇が閉じない、音と1〜3フレーム遅れ）／カメラの不可能なグライド／音の不一致
- 振り向き（横顔→正面）は避ける。カメラは固定か slow push-in のみ（6秒で3〜5%）。動きの強さ指定がある道具では20〜45%から
- 尺の黄金律（地域横断で一致）：生成3〜5秒、使うのは2〜4秒。30秒の作品＝10〜15カット。顔アップの長回しと両手の見える全身歩行は尺の外へ
- 歩行はプロンプトでなく実写参照のモーション転送が決定打。「少し柔らかい画質＋正しい重さ＞鋭い画質＋浮遊」
- 文字とロゴは画面内で読ませない。必要なら後から実物合成
### 後処理
- フィルムプリント系LUT（Kodak 2383等）を50〜70%、グレインは毎フレーム変化する時間方向ノイズで8〜15%、ブラーは1px未満、飽和を落とす。静止画グレインの流用は同罪
- 180°シャッター相当：24fps→1/48、30fps→1/60のブラー量が自然。ちらつきはDeflicker
- 音：環境音と足音を足す。無音＋汎用BGMだけはショールーム感が出る
### 検品の順番（11段階の要約）
通常速度・音あり→無音2倍速→一時停止して100%（顔・手・足元接地・文字）→0.25倍速で時間方向（目・口・髪際・背景の縁）→物理→光→スマホ痕跡→判定：単独の違和感は保留、3つ重なれば作り直し

## 第2ラウンド追記（2026-11-19、全世界再調査。正本レポートは research_notes/photorealism-round2-2026-11-19/report.md）
### 診断の線引き：質感層は直せる、構造層は再生成しかない（中国で定式化）
- 処理順序は固定：構造的ボツを落とす → テクスチャを補う → フレーム間の抖動を抑える → 色。単フレームは良いのに再生すると「抖く」ことが、観客が嘘と判定する主因。第3步を省かない
- テクスチャ補正の強度は顔と背景で分ける。検収は逐フレームでなく通常速度の通し見で、注意力が顔に引っかかったら不合格
- 検収の3箇所：会話時の口（唇だけ動き顎が死んでいないか）、振り向き時の耳と生え際、手の指と服の裾
- 動画版の均一さ問題：テクスチャの呼吸（同一テクスチャが隣接フレームで微変形・漂移）、輪郭の蠕動、小物の出現・消失。光影の破綻は後期で直すのが最も難しい（元情報が無い）ため、光は生成時点で固定するのが先
### フリッカー後期の正しい順序（超分と鋭化を先にやると悪化する）
- 順序：時域降噪（時間半径1〜3フレーム）→ 光流平滑 → 補間（RIFE等）→ 超分・調色。先に超分するとフレーム独立の高周波が拡大され閃きが目立つ。先に鋭化してから補間すると縁が抖く。統一調色は補間の後
- 生成側の安定化：運動強度は 0.3〜0.5 から始め、単クリップは3〜4秒に抑える。同じショットを3〜5シード生成して最も安定したものを選ぶ方が、プロンプト改修より効く
### カメラの失敗は「1回だけ・時刻つきの出来事」として書く（英語圏の実演プロンプトが具体化）
- 欠陥を「性質」でなく「出来事」で書く：自動焦点が中盤に1回だけ迷って戻る／自動露出が光の変化で1回だけステップ状に変わる／約3秒の急な動きでローリングシャッター歪み／終わりはフェードでなく唐突なカット
- 被写体の演技も指定する：「撮られていることに半分気づき、半分無視しようとする」照れた笑いが、ポーズとの差になる
### 色温度の混在は実在感の信号（「光源1つ」との整理）
- 統一すべきは光の方向と影の整合。色温度は窓の昼光＋室内の暖色灯のように実在の組み合わせで混在させてよい（mixed daylight and tungsten が最も強い実在感の信号という実務ガイドがある）。ただし顔の上で色が割れる使い方はしない
### モデル別の作法の更新
- Kling：image-to-video ではフレームに見えているものを書かず、動きと結末だけを書く。公式は「否定指示はエラーを増やす」と明言（基本は望む状態を書き、否定は限られたものだけ。他モデルと逆の点に注意）。Omni Reference と Keyframes は同一生成で併用不可。被写体を Element にバインドするとカメラ移動でも顔が揺れにくい。一鏡到底が欲しければ `one continuous shot` と明言する（明言しないと勝手に切る）。対白2文を5秒に詰めると尻切れするので、対白には8〜10秒を与える。運用は Flash で分鏡を通し → 本番モデルで出す二段構え。Professional モードはモーション従順性を下げることがあり、Relevance 最大で従わせると終盤の顔ブレと色の持ち上がりが出る。I2V ではカメラ指示（zoom / pan）が効きにくいという実演確認もある
- Seedance：プロンプト内で `@Image1` 等と素材をタグ付けし、用途（主体／運鏡／音声）を明示する「導演式」が作法。運鏡の映画感は等速でなく速度変化（推近は先慢後加速、環繞は呼吸のような起伏、停止前の減速）。参照の受理条件の実測：顔のクローズアップ参照はエラーで落ち、腰上（顔がフレーム高の約1/4）と全身は通る。参照は「寄れば良い」ではない。2.5 は30秒・参照最大50アセット、2.5 Flash（2026-11-12）は約2倍速と引き換えに720p上限・参照削減
- Veo 3.1 は「新版」ではなく移行が現在地（Gemini API の preview は2026-10-22終了、移行先は Gemini Omni 1.1 Flash。GA版は存続）。前提を置き直すこと
### 同一性の3点セットと配分則
- 3点セット：①参照画像で「誰か」を毎ショット与える ②I2V で承認済みの顔を第1フレームに固定する ③前ショットの最終フレームを次ショットの開始に繋ぐ。どれか1つでは足りない
- 4ビューパック（front / three-quarter / profile / wardrobe）は同一ファイル・同一順序・同一比率・同一品質で凍結。変更は1回に1変数。横顔とワイドで最初に崩れるため、その2つを先に検査する
- 時間と顔サイズの劣化則（二次引用・数値は未確認）：約16秒を超えると、また前回登場から時間が空くほど一貫性が急落する。顔が小さいほどドリフトする。配分：同一性の見せ場はミディアムショット、ワイドは歩行など顔が要らない場面へ
### 「人はそのまま、表情と空気だけ変える」型（韓国）
- 動かしてよい要素を限定する：瞬き、微細な表情変化、髪と裾のわずかな揺れ、非常にゆっくりしたズームだけ。「生きている写真」を作り、アイデンティティを壊さないことを最優先にする型
- 表情は形容詞の投与量で制御する：笑顔が強すぎたらポジティブ語彙を減らし `gently / softly smile` に絞る
### 媒体（medium）を先に定義し全工程で固定する
- 媒体がカメラ運動・レンズ・色だけでなく人物の振る舞いまで決める。未指定だと Hollywood＋iPhone＋ドキュメンタリーが混ざり半CG感になる。目指す実写参考をAIに渡して cinematography / color grading / film type を逆算させ、得た媒体キーワードを全画像・全動画プロンプトに共通で貼る
- プロンプト雛形は Style / Location-Setting / Action / Sound の4欄。音欄には必ず `no music` を入れる（モデルが勝手に音楽を付けるため）
- キービジュアルに2人を入れておくと動画モデルが身長差を学習する（スケール参照）。4:3 はドキュメンタリー感になり磨かれた映画感が消える
### Draft検証と編集救済
- Draft 検証：低解像度（例：480p）で動きだけを安く確認し、OKなら本番解像度で再生成する（ドラフトの動き＋参照の質感で新規生成するので、単なるアップスケールと違う）。あえて上げず柔らかく圧縮されたままの方が実写らしい場合もあり、アップスケールを省略する判断も正当
- 編集で生成ミスを消す3手：①間違った目の色などは末尾2フレーム程度を切る ②反応の理由付けは音だけを前に伸ばしてクロスフェード（足音を先に聞かせてから振り向く） ③生成間の距離の矛盾は次ショットの冒頭を切って動作の途中で入る
- 統一仕上げは調整レイヤーで全クリップ一括：Halation（ハイライトの滲み）＋Glow（広い拡散）＋Grain。共通の質感を上から被せると「同じカメラで撮った」と目が認識する。グレイン素材のオーバーレイは Opacity 30% が実演値
- モデルの分業：「1モデルで通さない」。人物の初回生成だけ質感最良のモデル → 状況展開は別の編集系モデル → 動画は動き系モデル。大動作を避ける実写用途では、最上位モデルでなく安いモデルの方が適する場面もある
### 動画の鮮明さ（2026-11-19追加指示の軸）
- 「作る vs 補正する」を分ける：生成系アップスケール（新しいピクセルを作る）とシャープ系（既存データの補正）は別物。生成系のシャープを切って補正系に一本化すると制御性が上がる。倍率は出力解像度に正確に一致させる（1080→2160 は 2x）
- 鮮明さの判断は全体表示で行う。等倍で覗いて調整すると必ず過剰になる（静止画編の検品分離と同じ）
- 動画では「柔らかさ・ピントの漂い」自体が実写の仕様になる場面がある（camcorder 指定：autofocus hunting / auto exposure drift / motion smear / softness）。最終解像感は後段アップスケールでなく再生成で得る方法もある
- アップスケーラの設定値は作者間で衝突する（強いシャープ値の主張 vs 慎重論）。数値は鵜呑みにせず、1秒プレビューで前後比較し「少しシャープ過ぎる」手前で止める。既にピントが合っている素材に Focus Fix 系は使わない
