# ヴォニッチ手稿「試しの解読」ノート

- 実施日: 2026-11-14
- 方針: **読めたふりはしない。** ここに書く数字は、公開転写ファイルを実際に数えたものだけ。推測は「推測」と明記して分ける。

## やったこと

1. 公開されている EVA 転写テキストを voynich.nu から入手した。
   - 主に使ったのは **IT2a-n.txt**（高橋健氏の全面転写、EVA 基本文字版、IVTFF 2.0 形式、LSI ファイルから抽出されたもの）。比較用に ZL3b-n.txt（Zandbergen–Landini 転写）も取得したが、集計には高橋転写を使った。
   - 本文行（locus）4,443 行を抽出。判読不能文字 `?` を含む 126 語（`?` は全文で 228 文字）は集計から除外した。
2. 基礎統計を実測した（文字頻度、語の頻度、語長、繰り返し、編集距離、文字の位置依存、エントロピー）。
3. 素朴な解読の試行を1つ行った: **単純換字式**。ヴォニッチ側の文字頻度順位を、ラテン語の文字頻度順位にそのまま対応づけて置換した。ラテン語側の頻度は、カエサル『ガリア戦記』第1巻（The Latin Library 公開テキスト、8,179 語・48,281 文字）を実際に数えて得た。
4. 既知の研究状況を公開資料で裏取りした（下記「研究の現状」）。

## 実測の数字

### 全体像

| 項目 | 実測値 |
|---|---|
| 総文字数（EVA 文字、語の切れ目を除く） | 167,335 |
| 文字の種類数 | 22 種（うち 100 回以上使われるのは 19 種） |
| 語数（トークン） | 32,314 |
| 語の種類数（タイプ） | 7,798 |
| 1 回しか出ない語（ハパックス）の割合 | 全タイプの 71.3%（5,558 種） |
| 語長の平均 / 中央値 | 5.18 文字 / 5 文字 |
| 最頻出語 | `daiin`（690 回） |

頻出語トップ10: `daiin` 690、`ol` 454、`chedy` 427、`aiin` 391、`shedy` 378、`chol` 320、`ar` 309、`or` 294、`chey` 273、`dar` 270。

語長分布は 5 文字を頂点とする釣鐘型で、1〜2 文字の短い語は全体の **7.75%** しかない。対して『ガリア戦記』第1巻では 1〜2 文字の語が **14.27%** を占める（ラテン語には in, et, a, ex のような短い機能語が大量にある）。

### 繰り返しと「1文字違いの兄弟語」

- 同じ語が隣り合って繰り返される箇所: **269 組**（3 連続きは 7 組）。例: `chol chol` 18 回、`qokeedy qokeedy` 18 回、`daiin daiin` 16 回。
- 編集距離1（1文字の置換・挿入・削除）で結ばれる「兄弟語」を持つ語は、全 7,798 タイプ中 **6,540 タイプ（83.9%）**。例: `daiin` の兄弟は `aiin`、`aiiin`、`daein` など。`chedy` と `shedy` のような組も頻出語同士で結ばれている。
- つまりこの語彙は、少数の部品を少しずつ変えて量産されたような形をしている。自然言語の語彙では、頻出語同士がここまで網の目のように1文字違いで連なることはない。

### エントロピー（ランダムさの指標）

語内部の文字連なりで測った条件付きエントロピー（前の1文字から次の文字がどれだけ予測できるか）:

| | 1文字エントロピー | 条件付きエントロピー |
|---|---|---|
| ヴォニッチ（高橋転写） | 3.87 bits | **2.14 bits** |
| ラテン語（『ガリア戦記』第1巻、同じ方法で実測） | 3.99 bits | **3.13 bits** |

ヴォニッチの本文は、ラテン語よりはるかに「次が読める」— つまり規則的で冗長な並びになっている。

## 試行の結果（なぜ読めないか）

頻度順位による置換対応（ヴォニッチ → ラテン語）は、`o→e, e→i, h→u, y→t, a→s, c→a, d→r, i→n, k→o, l→m, …` というものになった。これで第1フォリオ表面（f1r）の冒頭を読むと:

```
原文: fachys ykal ar ataiin shol shory cthres y kor sholdy
置換: gsautc tosm sl spsnnd cuem cuelt apulic t oel cuemrt

原文: ooiin oteey oteos roloty daiin otaiin or okan
置換: eennd epiit epiec lemept rsnnd epsnnd el eosd
```

ラテン語の単語は1つも現れない。最頻出語 `daiin` は `rsnnd` になる。よく使うラテン語約100語のリストと照合しても、全文 32,314 語のうち一致は 136 語（0.4%、偶然の一致レベル）にとどまった。

これは「対応表が下手だった」からではない。実測が、**単純換字＋自然言語という仮説そのもの**と矛盾する:

1. **エントロピーは換字では変わらない。** 文字を1対1で置き換えても条件付きエントロピーは保存される。実測値はヴォニッチ 2.14 bits 対ラテン語 3.13 bits。差が約1 bit ある以上、この本文は「ラテン語（や同程度のエントロピーを持つ欧州の言語）を単純換字したもの」ではあり得ない。これは数学的な不可能性であって、試行回数の問題ではない。
2. **位置のクセが説明できない。** 換字では、暗号側の各文字は平文側の文字の位置分布をそのまま引き継ぐ。だが頻出するラテン文字（e, i, a, u, t, s…）はどれも語頭・語末に自由に現れるのに、ヴォニッチの `e` は語の両端にほぼ立てず、`h` は語頭に立てない。対応先になり得る平文文字が存在しない。
3. **語の形が違う。** 語長が5文字前後に固まり、短い機能語が乏しく、語彙の84%が1文字違いの兄弟語で連なる。この「型にはまった生成感」は、自然言語の語彙の統計とは別物である（Timm & Schinner らが指摘する「自己引用式の生成」仮説とも整合する形）。

したがって今回の試行の結論は「読めなかった」ではなく、**「この読み方では原理的に読めないことが分かった」**。残る可能性は、複雑な暗号（同音換字・多表式・略記体系など）、未知の言語、あるいは意味を持たない生成テキストなどだが、今回の実測だけではそのどれとも断定できない。断定しないのが誠実な範囲である。

## 研究の現状（裏取り済み）

- **所蔵**: イェール大学 Beinecke Rare Book & Manuscript Library、請求記号 **MS 408**。1912年に古書商 Wilfrid Voynich がイタリアで入手し、1969年に Kraus から同館へ寄贈された。
- **年代**: 羊皮紙の放射性炭素年代は **1404–1438 年（95%信頼区間）**。2009年にアリゾナ大学の AMS 施設が4サンプル（f8, f26, f47, f68）を測定し、2011〜2012年に公表された。注意点として、これは羊皮紙（動物の皮）の年代であり、筆記そのものの年代を直接示すものではない。ただしインク・顔料の分析も15世紀の材料と矛盾しない。
- **2017年の「解読成功」主張（Nicholas Gibbs）**: Times Literary Supplement に「ラテン語略記で書かれた女性の健康マニュアル」とする説を発表。中世写本学の専門家（Lisa Fagin Davis ら）から「文法的に意味をなすラテン語になっていない」と批判され、学界の支持は得られていない。
- **2019年の「解読成功」主張（Gerard Cheshire）**: ブリストル大学の研究員（当時）が Romance Studies 誌に「原ロマン語（proto-Romance）」説を発表。大学がプレスリリースを出したが、言語学者・中世研究者からの批判を受けて**2日後に撤回**された。再現性のなさが問題視され、現在も合意は存在しない。
- **現状**: その他の主張（2016年の Kondrak & Hauer によるヘブライ語説など）も含め、**2026年時点で専門家の検証に耐えた解読は存在しない**。未解読のままである。
