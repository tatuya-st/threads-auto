# 三姉妹のベース服装とローテーション基準（2026-11-23、マスター指示で構築）

正本画像：~/workspace/imagine_media/media-generation-2-157cm-46kg-0-f6d119de-d7fb-4fa9-aff1-47c25898e97b.webp
運用の原則：各人のベース（看板服装）を軸に、色・型の世界観の中でローテーションする。他人の基調色とは被らない。同じ服の使い回しはしない（素材・色味・丈・小物で変化をつける）。服装記録には髪型・メイク・バッグ・靴まで併記する。

## 楓（長女・28・165cm）
- ベース：黒タートルネック＋ベージュのロングフレアスカート＋黒パンプス。髪はハーフアップ、眼鏡なし。
- 基調色：黒×ベージュ。差し色はボルドー・深緑など大人の色を1点だけ。
- 服装ローテ：黒ニット系トップス×ベージュ系スカートの素材・丈違い／黒のワンピース／ベージュのコート・カーディガン。スカートは膝下丈が基準。
- 靴：黒基調（パンプス・ブーツとも黒、形は変える）。
- メイク：ローズベージュ。眉はゆるい平行アーチ＋明るめブラウン（メイク仕様書どおり）。
- 髪型ローテ：ハーフアップが基準。高めのウェーブポニーテール、ダウンスタイル、眼鏡ありの日も回す。
- バッグ：黒基調の上品な形（フラップ付きショルダー等）。

## 京（次女・24・160cm）
- ベース：グレージュのオフショルニット＋ダークブラウンの膝下タイトスカート＋黒シアーストッキング＋キャメルのパンプス。髪はダークブラウンのボブ。
- 基調色：グレージュ×ブラウン×キャメル。
- 服装ローテ：オフショル系トップスの色・素材違い（出す場所は肩が基準＝85項）／キャメル系ニットワンピース／カーディガン＋タイトスカート。スーツ・ジャケットの固い形は使わない（マスター不採用）。
- 靴：キャメル系（パンプス・ブーツとも、形は変える）。
- メイク：グレージュ。眉は自然な平行気味（メイク仕様書どおり）。
- 髪型ローテ：ボブが基準。ストレート／外ハネ／片耳かけ／前髪の有無で変化。
- バッグ：キャメル〜ブラウン系のレザー調。

## 町（三女・18・157cm）
- ベース：淡いピンクのニットワンピース（ウエストを細いベルトで絞ったフィット＆フレア、膝下丈）＋黒シアーストッキング＋焦げ茶パンプス。髪は茶のセミロングウェーブ＋前髪。
- 基調色：ピンク×クリーム×コーラル。
- 服装ローテ：ピンク系ワンピースの色味・素材違い／クリームのカーディガン＋フレアスカート。ウエストマークは必須（ウエストのラインが見えない形は「太って見える」ため不合格、マスター指摘）。
- 靴：焦げ茶系（パンプス・レースアップブーツ）。
- メイク：ピンク〜コーラルの淡色。眉は自眉に近いふんわり（メイク仕様書どおり）。
- 髪型ローテ：セミロングウェーブが基準。ハーフアップ／編み込み／ストレートで変化。
- バッグ：焦げ茶〜ピンク系の小さめの形。
