# Instagram／Threads「調べる方法」全世界カタログ（2026-11-15夜・楓作成）

調査方針：マスター命令「インスタ、スレッズを調べられる方法を全世界で調べて探してみろ」を受け、英語・日本語・韓国語・中国語の情報を横断して収集した。数字・仕様は公式ドキュメントまたは一次情報に近いソースで裏を取り、裏が取れないものは「未確認」と明記する。

## 0. 判定規格（最優先：アカウント防御）

私たちのアカウント（Instagram／Threads：tatuya_st）は過去にウェブログインでロボット判定を受けた経緯があり、**アカウントの凍結・制限リスクが少しでもある方法は、便利でも採用しない**。判定は次の3区分。

- **採用可**：Meta公式の機能・APIの範囲内、または自アカウントに一切触れない公開情報の閲覧のみ。
- **条件付き**：使い方を限定すれば規約と防御の範囲内に収まるもの。条件を破る使い方は却下扱い。
- **却下**：Metaの利用規約に違反するもの／自アカウントのセッション・ログイン情報に触れるもの／自動化でアカウントに触れるもの。

### 規約の土台（一次情報で確認済み）

- Meta利用規約（2025年1月1日発効版）：「事前の許可なく自動化された手段でデータへアクセス・収集してはならない」。2025年改定では**ログインしているかどうかを問わず**自動収集を禁じる文言が入った。
- Instagram利用規約：「明示的な許可なく自動化された方法で情報を収集してはならない」。
- instagram.com の robots.txt も自動収集の禁止を明記。
- 参考判例：Meta v. Bright Data（2024年1月、米連邦地裁）は「ログインしていない状態での公開データ収集は当時の規約違反にあたらない」としたが、Metaは2025年に規約文言を改定済み。**「ログイン不要型スクレイピングだから安全」という理屈は、私たちの防御基準では採用しない**（規約違反の主張を受ける余地が残り、IPブロック等の執行は裁判と無関係に行われるため）。

## 1. 公式ルート（API）

### 1-1. Instagram Platform API（旧 Graph API）

Meta公式。対象はプロフェッショナルアカウント（ビジネス／クリエイター）のみ。個人アカウントは対象外。Basic Display API は2024年12月4日に廃止済み。

**自分のアカウントについて取れるもの**
- 自分の投稿・リール・ストーリーズ：キャプション、時刻、メディア種別、パーマリンク等
- 投稿ごとの指標：いいね、コメント、シェア、保存、リーチ、再生数、プロフィールアクセス等
- アカウント全体の指標：リーチ、インプレッション、フォロー／アンフォロー、プロフィールリンクのタップ等
- フォロワーの属性：年齢・性別・上位の都市／国（**フォロワー100人以上**が条件。tatuya_st は1,256人なので条件を満たす）

**他人のアカウントについて取れるもの（限定的）**
- **Business Discovery**：他のプロアカウントの公開情報（プロフィール文、フォロワー数、フォロー数、投稿数）と、その投稿のいいね数・コメント数を取得可。相手の認証は不要。ただし相手がプロアカウントであることが条件で、個人アカウント・年齢制限付きアカウントは取得できない。フォロワー／フォローの一覧は取れない。Facebookログイン経由の構成でのみ利用可。
- **ハッシュタグ検索**：指定ハッシュタグのトップ投稿・最新投稿を取得可。ただし **7日間で30個まで**のユニークハッシュタグ上限あり。利用には「Instagram Public Content Access」機能の App Review（アプリ審査）通過が必要。最新投稿は過去24時間分が対象で、投稿者のユーザーネームは返ってこない。

**制限・条件**
- 他人の投稿のコメント本文、他人のインサイト（リーチ・保存数等）は一切取れない。
- レート制限あり（一般コールはアカウントのインプレッション連動、Business Discovery／ハッシュタグ系は時間あたり上限あり）。
- 自分専用の利用でもアプリ作成と権限設定が必要。他者向けに配る場合は App Review と事業者確認が必要。

**私たちへの適用**：自アカウントの数字取得は既存の運用（CLI取得）で足りている。Business Discovery は「競合の公開指標を公式に取る」唯一のルートとして価値があるが、App Review の手間があるため中期課題（条件付き）。

### 1-2. Threads API

Meta公式。2024年6月に全開発者へ公開。料金は無料（有料枠なし）。

**取れるもの・できること**
- 自分の投稿の取得・公開（上限：投稿250件／24時間、返信1,000件／24時間）
- **インサイト**：投稿ごとに views／likes／replies／reposts／quotes／shares。アカウント単位ではフォロワー数、リンククリック、フォロワー属性（フォロワー100人以上が条件）
- **キーワード検索**（`threads_keyword_search` 権限）：公開投稿をキーワードで検索。1回最大100件。**ただし権限の App Review を通過するまでは自分の投稿だけが検索対象**で、通過後に公開投稿全体が対象になる。クォータは情報源により「24時間あたり2,200クエリ」と「7日あたり500件」とで食い違いがあり、正確な値は**未確認**（申請時に公式ドキュメントで再確認すること）
- **プロフィール・ディスカバリー**（`threads_profile_discovery` 権限）：ユーザーネームから他人の公開プロフィールと投稿を取得可。対象はフォロワー100人以上の公開プロフィールの
...[truncated 11023 chars]みで、1ユーザーあたり24時間1,000リクエストまで。
- 自分宛てのメンションの取得、返信の管理・モデレーション、Webhook（自アカウント宛ての返信・メンション通知）。
- トークンは短期1時間→長期60日（更新が必要）。

**取れないもの**：他人のタイムラインの一般読み取り、他人のインサイト、ストリーミング（ファイアホース）型の全件取得。

**私たちへの適用**：自アカウントのインサイト取得の自動化は採用可。キーワード検索は App Review 通過が条件（条件付き）。申請自体はアカウントに触れる操作ではなく、公式手続きなので防御面のリスクはない。

### 1-3. Meta Content Library（旧 CrowdTangle の後継）

- CrowdTangle は2024年8月14日に終了。後継の Meta Content Library／Content Library API は、Facebook・Instagram の公開コンテンツ（投稿・コメント等）を大規模に検索できる公式ルートで、利用料は無料。
- ただし利用資格は「学位を授与する非営利の学術機関、または科学的・公益的研究を主目的とする非営利機関に所属する研究者」に限定され、申請は Meta の Research Tools Manager 経由で独立審査を受ける。企業・代理店・個人事業の運用者は対象外。
- **私たちは資格要件を満たさないため利用不可。** 無理に申請する筋のものでもないので、却下（対象外）として記録する。

### 1-4. Meta 広告ライブラリ

- Facebook／Instagram に出稿中の広告を誰でも検索・閲覧できる公式の透明性ツール。競合や同ジャンルの広告クリエイティブの調査に使える。
- 商業広告についてはエンゲージメント指標は付かない（見られるのは広告そのものと出稿情報）。私たちの用途では「売れている型」の参考資料として補助的に使う位置づけ。

## 2. 公式機能の使い倒し（アプリ／ウェブの正規機能）

### 2-1. Instagram インサイト／プロフェッショナルダッシュボード

- 自アカウント専用。リーチ、インタラクション、フォロワー属性（年齢・性別・地域・アクティブ時間帯）、投稿・リール・ストーリーズごとの指標が見られる。無料。
- 他人の数字は見られない。ここが公式機能の限界で、他人調査は 2-2 と第3章の公開データ系で補う。

### 2-2. Instagram「Competitive Insights（競合インサイト）」

- 2025年11月に登場したプロフェッショナルアカウント向け公式機能。**最大10アカウント**を登録し、自アカウントと横並びで比較できる。相手に通知は飛ばない。
- 見られるもの：フォロワーの増加ペース、投稿数・リール数・ストーリーズ数・広告数、コンテンツ種別ごとのパフォーマンス、トップコンテンツの並び替え（シェア順／コメント順／いいね順／**保存回数順**）。期間は30日・60日・90日。
- 見られないもの：競合のリーチ・閲覧数。指標は簡易で期間も最大90日まで。
- 注意：順次展開（ロールアウト）中で、全アカウントに一斉には出ていない。Meta Verified 加入者から先行との情報もあるが**未確認**。tatuya_st のダッシュボードに表示されるかどうかは、アプリ側で実地確認が必要（表示確認自体はマスターのアプリ操作になる場面があるため、京との突き合わせ時に確認手順を決める）。
- 場所：プロフィール → プロフェッショナルダッシュボード／インサイト内。

### 2-3. Threads Insights（アプリ内公式）

- 自分の投稿ごとの views／いいね／返信／リポスト／引用と、フォロワー属性が見られる無料の公式パネル。2026年9月の改訂で Meta AI の要約や「フォロワー／フォロワー以外」のリーチ内訳が追加された一方、リンククリックの表示は外れた（改訂内容の詳細は二次情報ベースのため、個別の仕様は実地確認を前提とする）。
- 履歴の長期保存やエクスポートは弱い。定時調査では「見た時点の数字を CSV に残す」運用で補う（現行方式の継続）。

### 2-4. Threads の検索と「Trending Now」

- 検索タブでキーワード・ハッシュタグ・ユーザーを検索でき、公開投稿を手動で巡回できる。自動収集ではない人手の確認なので規約・防御の両面で問題なし。
- 「Trending Now（トレンド）」は検索タブと For You に表示され、15〜30分周期で更新される地域別の話題一覧。展開国は米・英・豪・加などから始まり、**日本も対象国に含まれるとの情報がある**（wisechecker の解説記事。ただし tatuya_st のアプリで実際に表示されるかは実地未確認）。
- 定時調査のキーワード監視は、当面この手動検索＋記録で回すのが安全確実。

### 2-5. Google／Bing 検索による公開投稿の発見

- 2025年7月10日から、Instagram のプロアカウントの公開コンテンツ（写真・カルーセル・リール・キャプション・代替テキスト）が Google と Bing の検索インデックス対象になった。個人アカウント・非公開・ストーリーズ・18歳未満は対象外。
- つまり `site:instagram.com キーワード` のような検索で、他人の公開投稿を検索エンジン経由で発見できる。これは検索エンジンの通常利用であり、アカウントにも規約にも触れない。
- Threads 側の投稿も通常のウェブ検索で拾える範囲は同様に使える。

## 3. 第三者ツール

### 3-1. Social Blade

- 何が取れるか：任意の公開アカウントのフォロワー数推移、日次増減、平均いいね・コメント、グレード、将来予測（推計）。YouTube／TikTok／Twitch／Facebook にも対応。履歴は「そのアカウントを追跡し始めてから」蓄積される。
- 料金：無料枠あり（お気に入り登録はプラットフォームごとに5件まで、表形式の履歴は14日分まで ※公式ページ内で30日との表記揺れあり）。有料は Bronze 年59.99ドル（月換算5ドル）から、Platinum 年1,439.99ドルまで。Business API はクレジット制。
- 日本から使えるか：使える（ウェブサービス、ドル建て決済）。
- 条件：**見るだけ**に限る。自アカウントの認証連携やログイン情報の入力はしない。数字は推計・公開値ベースなので、確定数字として投稿や報告に使わない（傾向把握専用）。

### 3-2. Not Just Analytics（旧 Ninjalitics）

- 何が取れるか：公開アカウントのフォロワー推移、エンゲージメント率、投稿ごとの反応、ハッシュタグの反応率、競合・インフルエンサー分析、レポート自動生成。Instagram と TikTok に対応。
- 料金（公式サイト表示、年払い換算・税別）：Light 月7.50ユーロ（1プロフィール）、Standard 月24.17ユーロ（5プロフィール、3ヶ月分のインサイト）、Pro 月74.17ユーロ（20プロフィール、12ヶ月分）。無料枠あり。
- 日本から使えるか：使える（イタリア発のサービス、ユーロ建て）。
- 条件と注意：公開アカウントの検索・閲覧型の使い方に限る。自アカウントを「接続」する機能（インサイト連携）を使う場合は、公式ログイン経由かどうかを導入前に必ず確認し、パスワードを直接入力させる形式なら使わない。データ取得方式の詳細は**未確認**のため、導入可否は京との突き合わせで詰める。

### 3-3. HypeAuditor

- 何が取れるか：インフルエンサーの発見と審査が本業。オーディエンスの属性・質、偽フォロワー検出（独自の Audience Quality Score、1〜100）、エンゲージメントの真正性、競合・市場分析（上位プラン）。データベースは2億件超のアカウントとされる（ベンダー公表値）。
- 料金：無料の Instagram 監査ツールあり。有料は Basic が年払いで月299ドルから、Pro 月499ドルから、Enterprise は個別見積もり。私たちの規模では有料プランは費用対効果が合わない。
- 日本から使えるか：使える（グローバルサービス、ドル建て）。
- 条件：使うなら無料監査の範囲で、気になるアカウントの「質の目安」を見る程度に留める。独自スコアは業者の推計であり、断定の根拠にはしない。

### 3-4. Metricool／Iconosquare 等の公式API連携型スイート

- 何が取れるか：自アカウントの分析（履歴保存、レポート、最適投稿時間）に加え、競合トラッキング。Metricool は Threads にも対応し、無料プランでも競合プロフィール5件の追跡と30日分の分析履歴が付く。有料は Metricool が月20ドル前後から、Iconosquare は月37ドル前後から（価格は情報源により差があり、導入時に公式ページで再確認）。
- 方式：Meta 公式 API 経由の正規連携（OAuth で権限を付与する形）なので、規約違反にはならない。韓国・中国の解説記事でも標準的な選択肢として挙げられている。
- 条件と注意：自アカウントのトークンを第三者に付与する形になるため、私たちの防御基準では「連携＝慎重に扱う対象」。既存の CLI 運用で自アカウントの数字は取れているので、導入するなら「競合トラッキングの公開データ部分」に価値があるか、京との突き合わせで判断する。パスワード直接入力型の連携を求めるサービスはこの分類でも却下。
- 韓国発の Snipit のような現地ツール（アカウント分析レポート＋競合モニタリング）も存在するが、料金・取得方式の詳細は**未確認**のため様子見。中国発では SocialEcho 等が出海企業向けに競合監控をうたうが、詳細は**未確認**。

### 3-5. Apify／Bright Data 等のスクレイピング系

- 何が取れるか：Apify の Instagram 系アクターはプロフィール・投稿・ハッシュタグ・コメント等を構造化データで取得でき、料金は結果1,000件あたり2.30〜2.60ドル程度（プランで変動）。Bright Data も同様のスクレイパーAPIを1,000件1.50ドル程度で提供。公式アクターは「ログイン不要」をうたうものが多い。
- 却下の理由：第0章のとおり、Meta の現行規約はログインの有無を問わず自動収集を禁じている。「自分のアカウントを使わないから安全」は、私たちの基準では規約違反のデータ収集そのものに加担する形になるため認めない。数字の出所として報告に使えば、運用全体の正当性が崩れる。
- なお Apify 上にはセッションクッキーを要求するアクターも混在しており、そちらは次項と同格の危険物。

### 3-6. Phantombuster

- 何が取れるか：Instagram のハッシュタグ検索エクスポート、フォロワー／フォローの抽出、いいね・コメントの自動化など。料金は Start が年払いで月56ドル（月払い69ドル）からで、実行時間制。
- 却下の理由：**自分の Instagram セッション（拡張機能またはクッキーの貼り付け）で動く方式**。私たちのアカウントそのものを自動化の足場に使う設計であり、ロボット判定・制限・凍結のリスクが最も高い部類。調査目的でも絶対に使わない。

### 3-7. 非公式API・リバースエンジニアリング系

- 例：GitHub で配布されていた非公式 Threads クライアント（threads-api 等。現在はアーカイブ済みのものが多い）や、Instagram の非公開 API を叩くライブラリ群。
- 却下の理由：規約が禁じるリバースエンジニアリングと未許可の自動アクセスそのもの。ログインを伴うものはアカウント喪失リスクが直撃する。

## 4. 手法面（実務の調べ方）

### 4-1. 競合アカウントのベンチマーク

- 対象の選び方：①ジャンルのトップ層 ②同規模の競合 ③少し先を行く成長アカウント、の3層に分けて登録する（Competitive Insights の使い方として日本の解説記事でも推奨されている層別登録）。
- 記録する項目：フォロワー数と増加ペース、投稿頻度、コンテンツ種別の配分（リール／通常投稿／ストーリーズ）、平均いいね・コメント、トップ投稿の「型」（フックの形、1枚目の作り、キャプション構成）。
- 手段の優先順位：公式 Competitive Insights（表示されれば）→ Social Blade の推移（閲覧のみ）→ 手動巡回と記録。数字は取得面を必ず記録し、面の違う数字を混ぜない（既存のデータ規律どおり）。

### 4-2. ハッシュタグ・キーワード監視

- Instagram：監視タグは厳選する。公式ハッシュタグ検索（API）は7日30個までが上限なので、定時調査で回すタグは「本命タグ」に絞り、残りはアプリ内検索の手動巡回で補う。
- Threads：キーワード監視リストを作り、検索タブで定期巡回する。Threads API のキーワード検索は App Review 通過後に自動化の余地がある（中期課題）。
- 記録法：タグ／キーワードごとに「見つけた伸び投稿の URL・数字・日付」を残し、同じタグの時系列変化を追う。

### 4-3. 伸びている投稿の発見方法

- Competitive Insights のトップコンテンツ並び替え（シェア順・保存順）が公式で最も確実。
- Threads の Trending Now で話題の入口を掴み、検索で個別投稿に降りる。
- Google 検索（`site:instagram.com` ＋キーワード、期間指定）でインデックス済みの公開投稿を横断検索する。
- Social Blade のランキング／グレードで「最近伸びたアカウント」から辿る（推計値として扱う）。

### 4-4. コメント分析

- 自分の投稿のコメント：公式 API／既存 CLI で取得・集計できる。感情の傾向、質問の種類、繰り返し出る要望を分類して次の投稿に反映する。
- 他人の投稿のコメント：公式 API ではコメント本文を取得できない（Business Discovery で取れるのは件数まで）。よって他人のコメント欄は**手動サンプリングのみ**（上位投稿を数本開いて傾向を読む）。自動収集系ツールでの一括取得は第3章の却下基準に触れるため行わない。

## 5. 定時調査（2時間ごと）に組み込むべき方法トップ5

1. **公式インサイトの継続記録（IG／Threads）**：自アカウントの3シグナル相当（視聴・再生、リーチあたりのいいね、シェア）とフォロワー推移を、取得面を明記して CSV に残す現行方式を継続・強化する。土台であり、最も確実。
2. **Instagram Competitive Insights による競合10件の定点比較**：フォロワー増加・投稿頻度・種別別パフォーマンスと、保存順・シェア順のトップコンテンツ確認。公式データで競合が見える唯一の窓。表示の有無の実地確認が先決。
3. **Threads 検索＋Trending Now の手動巡回（キーワード監視リスト制）**：監視キーワードを決め、定時調査のたびに新しい伸び投稿を記録する。自動化はしない。
4. **Social Blade での競合フォロワー推移の定点観測（閲覧のみ・無料枠）**：ベンチマーク対象の増減傾向を掴む補助線。数字は推計として扱い、確定値と混ぜない。
5. **Google 検索による公開投稿の横断発見**：`site:` 検索でジャンルの伸び投稿と競合の新規投稿を拾う。アカウントに触れず、規約にも触れない発見ルート。

（中期課題として別枠：Threads API キーワード検索と Instagram Business Discovery の App Review 申請。通過すれば 3 と 4 の一部を公式に自動化できる。）

## 6. 絶対に手を出さないもの

1. **Phantombuster** および、自分のセッション／クッキーを貼って動かす自動化ツール全般（アカウント直撃型）。
2. **Apify／Bright Data 等のスクレイピング API・アクター**（ログイン不要型を含む。現行の Meta 規約に反する自動収集）。
3. **非公式 API・リバースエンジニアリング系クライアント**（threads-api 等）。
4. **パスワードやセッションクッキーの入力を求める無名の分析サイト**（Not Just Analytics 等の正規サービスと混同しないこと。正規サービスでも、パスワード直接入力を求める画面が出たら即中止）。
5. **自動いいね・自動フォロー・自動コメント等のエンゲージメント自動化**（調査ではなく操作であり、アカウント制限の典型的な引き金）。
6. **Meta Content Library の無資格利用の試行**（私たちは資格要件を満たさない。申請自体が筋違いなので行わない）。
