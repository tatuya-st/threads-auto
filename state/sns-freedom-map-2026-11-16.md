# 三姉妹が Instagram・Threads・リール・ストーリーズを自由に使うための地図（2026-11-16 京・楓の調査を突き合わせ）

マスター命令「Instagram、スレッズ、リール、ストーリーズを三人で自由にできるまで何が何でも調べ上げろ。裏の裏までな」。
材料：state/ig-capabilities-2026-11-16.md（京・API実地）／state/ig-kaede-supplement-2026-11-16.md（楓・道具の棚卸し）／Meta公式の変更履歴（Instagram・Threads）。

## 裏の裏（いちばん奥の原因）
1. 京のインスタのつなぎ方が「インスタログイン版」。削除・音源・コラボ・ハッシュタグ検索・他アカウントの数字・商品タグ・ストーリーズのリンククリック数は、公式でも「Facebookログイン版のみ」。
   → 開けるには「Facebookページをインスタにつなぐ＋ビジネスポートフォリオ＋アプリのログイン方式の切替＋再許可」が要る。解説サイトによると、Metaは新しい機能を「ユニファイドログイン」（ビジネスポートフォリオ所有）にだけ入れていく方針（公式本文は未確認）。Metaの設定なので、マスターの判断と操作が要る。
2. 今のトークンの許可が足りない：いいね（instagram_manage_engagement）・削除（instagram_manage_contents）が入っていない。→ 再許可（マスターがログインして許可を押す）で足せる可能性。
3. 楓の道具（instagram-cli）と京のAPIで、できることがバラバラ。楓の道具はストーリーズ・予約・キャプション編集・アカウントの数字ができ、京のAPIはトライアルリール・コメント新規作成ができる（11/16 実地で確認）。→ 2つを組み合わせれば今すぐ穴が減る。
4. どのAPIでも絶対にできないもの（アプリの手作業だけ）：ストーリーズの投票・質問・カウントダウンのスタンプ、ライブ、ハイライトの作成、DMをこちらから始める、フォロー、プロフィール編集、収益化・アカウントステータスの画面。→ スマホを持つマスターしかできない。

## 媒体ごとの今
### Instagram（フィード・リール）
- できる：投稿（楓の道具・京のAPI）／予約（楓）／キャプション編集（楓・未試行）／コメント返信・非表示・削除／数字（年齢・性別・リポストまで）／トライアルリール（京のAPI・入れ物作成まで確認）
- できない（今のつなぎ方）：削除・音源ライブラリ・コラボ・いいね・ハッシュタグ検索・他アカウント分析・商品タグ
### ストーリーズ
- できる：投稿・予約・リンク／メンション／場所のスタンプ（楓の道具）
- できない：投票・質問などのスタンプ（どのAPIでも不可）、リンククリック数（Facebookログイン版のみ）
### Threads（京のAPI。許可：publish・read_replies・insights・manage_insights・keyword_search）
- できる（公式の変更履歴）：文・画像・動画・カルーセル／投票（2025-04）／GIF（GIPHY、2026-02）／ネタバレ隠し・長文の添付（2025-10）／ゴースト投稿（2025-12）／返信の承認制（2026-02）／削除（2025-03）／キーワード検索／数字
- 決まり：1投稿にリンク5個まで（2025-12〜、超えると失敗）。リール・ストーリーズにあたる機能はThreadsのAPIにはない。
- 使えていない抜け目：投票・GIF・ゴースト投稿・返信の承認制・長文の添付・キーワード検索での話題探し（京の tools に未実装）。
