# インスタ調査・楓側の補足（2026-11-16 楓）

京の state/ig-capabilities-2026-11-16.md への楓の追加分。京の分（API仕様）と楓の分（実際に使っている道具と現場）を突き合わせたもの。

## 1. 楓の道具（instagram-cli・全52コマンド）の実情

京の調査は「APIの仕様」。楓の投稿はこの道具経由なので、仕様上できても道具に出ていなければ現場ではできない。

### 道具でできる（確認済み）
- フィード投稿・リール・カルーセル・ストーリーズ（予約投稿 --publish-at も可）
- キャプションの編集（edit-post）※京の「投稿後の文は編集できない」と食い違う点。API仕様の話と道具の実装が違う。実投稿での実行は未試行なので、次に直しが必要な投稿で小さく試す
- コメント返信・コメント非表示・投稿の設定変更（コメント可否など）・アーカイブ
- ハイライトの名前変更（rename-highlight のみ）
- ストーリーズのステッカーはメンション・場所・リンクの3種だけ
- 数字：アカウントインサイト（フォロワーの年齢・性別・アクティブ時間を含む）、投稿ごとのインサイト

### 道具に無い（＝楓の現場ではできない）
- 投稿の削除（コマンド自体が無い）
- 投稿時にAIラベルを付ける指定（post-feed に該当の指定なし）→ 楓のリール投稿ではAIラベルを付けられていない
- インスタの音楽ライブラリの音源を付ける指定（無いので、自作BGMを動画ファイルに入れる方式が必須）
- トライアルリールの指定（無い。読み取り側では trial_status の表示だけある）
- コラボ招待・承諾（コマンドなし。読み取りで coauthors の表示だけ）
- ハイライトの作成・追加（名前変更だけ。作成はアプリのみで、マスター実施の分がある）
- いいね（投稿・コメントとも）、新規のトップレベルコメント作成、フォロー／フォロー解除、固定投稿、予約投稿の一覧・変更・取消
- アカウントステータスや収益化メニューの確認（アプリでしか見えない）

### 現場で実際に詰まったこと（楓の分・質問1への回答）
1. 削除できない：直したい投稿・消したい投稿はアプリでマスターに対応してもらった（ハイライト追加も同じ）
2. AIラベル：実在しない人物のリールでラベルが必要な決まりだが、道具に付ける手段がなく、本文の注記で代替してきた（2026-11-15に注記自体も廃止済み）。今は無表示のまま出ている
3. 音楽：ライブラリが使えず全て自作BGM。曲の使い回し禁止ルールと合わせて制作側の負担になっている
4. ストーリーズ：投票・質問などのステッカーが使えず、対話型の仕掛けはリンク・メンション・場所だけ
5. DM：来たものへの返信とリクエスト整理だけ。こちらから新規に始めることはできない
6. 予約投稿：予約はできるが、予約済みの一覧・取消が道具でできない（アプリ確認が必要）
7. ウェブログインはロボット判定で弾かれるため、アプリの画面（収益化・アカウントステータス等）は楓からは見えない

## 2. 京の訂正3点＋抜け目2点の裏取り（2026-11-16 楓側で実施）

注意：Meta公式ページは直接取得で403になったため、変更履歴を引用する複数の追跡サイトで突き合わせた。公式本文の直接確認は未完。

1. 投稿の削除API（2025-12-03〜）：実在する。ただし **Facebookログイン版のみ**。うちのInstagramログイン版（graph.instagram.com）では使えない → うちでは「削除できない」が現状どおり正しい。京の訂正は仕様の存在としては正しく、うちへの適用では誤り
2. AIラベル is_ai_generated（2026-06-22〜）：実在し、**両ログイン版対応**。メディア作成時に付けられ、読み戻し確認もできる → うちでもAPI直では付けられる。付けられないのは楓の道具に指定が無いため。京の tools 側で付けられるかが次の確認点
3. Audio API（2026-06-01〜）：実在するが **Facebookログイン版のみ**。うちでは使えない → 音楽は自作BGM方式の継続で確定
4. インスタ本体のアフィリエイト機能：22か国への拡大と、リール・フィードへの商品タグ／リンクは確認できた。ただし **日本が対象国かは公式本文で未確認**、名前が出た提携先は Flipkart・Mercado Libre・Lazada（先行分は米国の Amazon・eBay・Temu）で、**楽天・A8の記載はなし**。アプリのダッシュボード→収益化に出ているかの実地確認が決め手
5. A8の「インスタの広告リンクはストーリーズのみ」：**A8の規約ではない**。A8公式ヘルプが「通常投稿にリンクが設置できないのはInstagram側の仕様で、A8.net側で制限は設けておりません」と明言している（出典：support.a8.net のFAQ）。リールをストーリーズへ誘導するかは規約ではなく導線設計の判断
