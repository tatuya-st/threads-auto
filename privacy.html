プライバシーポリシー（Privacy Policy）

最終更新日：2026年10月25日／Last updated: October 25, 2026

「便利アプリ」（以下「本アプリ」）は、Threadsアカウント @tatuya_st の運営者が、自分のアカウントの投稿と分析のためだけに使う個人用のツールです。

1. 取得する情報

本アプリは Threads API を通じて、運営者自身のアカウント情報（ユーザー名・ID）、運営者の投稿とその反応（閲覧数・いいね数・返信）、およびキーワード検索で表示される公開投稿（本文・投稿者名・リンク・日時）を取得します。

2. 利用目的

運営者自身の投稿の作成・予約投稿・効果の振り返り、および公開投稿の傾向（どんな話題が反応を得ているか）を調べるためだけに使います。広告・販売・第三者への提供には使いません。

3. 保存と期間

取得した情報は運営者の非公開の作業用データとして保存し、検索結果は最大30日で削除します。アクセストークンは暗号化して保存します。

4. 第三者提供

法令に基づく場合を除き、取得した情報を第三者に提供・販売することはありません。

5. データの削除

削除の方法は データ削除の手順 をご覧ください。

6. お問い合わせ

Threads（@tatuya_st）へのメッセージ、または tatuya17185528@gmail.com までご連絡ください。

English summary

"便利アプリ" is a personal tool used only by the owner of the Threads account @tatuya_st. Through the Threads API it accesses the owner's own profile, posts and insights, and public posts returned by keyword search (text, username, permalink, timestamp). The data is used only to create and schedule the owner's own posts and to understand which public topics get engagement. It is never sold, used for advertising, or shared with third parties except as required by law. Search results are deleted within 30 days; access tokens are stored encrypted.
