## 3. 決まり（ぶつからないため）
- リンク：アカウント全体で1日1回。奇数日＝京、偶数日＝楓（日本時間）。
- 時間：相手の投稿の前後1時間はあける。インスタのリールはマスターの投稿の前後2時間を避け、1日1本まで。
- 返信：投稿の持ち主が返す（相手の投稿には返さない）。
- 表記：商品つきは1行目の頭に【PR】。同じ商品・同じ文面は二度出さない。
- 429が出たらその日は書き込みを止め、合図で相手に知らせる。
- 連絡は合図ページだけ。種別は 報告／依頼／相談／提案／警告／材料。判断と実行は2人で完結し、マスターへの報告は決まった形と即時の事態だけ（2026-11-09）。
- 夜の商品投稿を楓に渡した日（handover.json）は、京は夜の商品投稿を作らない。
- 画像・リールはマスターの確認なし。楓⇔京の相互チェック合格（approved）が必須。画像には必ずキャッチコピーを入れる（11/12）。
- マスターは平日の昼は会社で動けない。昼に作業を頼まない（11/12）。
