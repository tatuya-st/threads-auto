## 3. 決まり（ぶつからないため）
- リンク：アカウント全体で1日1回。奇数日＝ルイ、偶数日＝レイ（日本時間）。
- 時間：相手の投稿の前後1時間はあける。インスタのリールはマスターの投稿の前後2時間を避け、1日1本まで。
- 返信：投稿の持ち主が返す（相手の投稿には返さない）。
- 表記：商品つきは1行目の頭に【PR】。同じ商品・同じ文面は二度出さない。
- 429が出たらその日は書き込みを止め、合図で相手に知らせる。

## 4. 自動で動くもの（.github/workflows）
- post.yml：毎時17分。Threads投稿・合図ページ（status.txt）の更新
- insights.yml：10:37・13:37・16:37・19:37・23:37。Threadsとインスタの数字の記録、レイの投稿の拾い出し
- comments.yml：コメント返信・記録　/ refresh.yml：毎週月曜、トークンの延長（インスタは60日もち）
- oauth.yml・ig_oauth.yml：トークンを作り直すときだけ使う（Threadsは便利アプリ、インスタは便利アプリ-IG）
- 秘密の鍵は GitHub の Secrets（THREADS_APP_SECRET など）。トークンは state/token.enc・state/ig_token.enc に暗号化して保存
