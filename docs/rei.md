## Threads投稿の共通ルール
- 本数：レイの投稿は1日2〜3本まで。ルイ側と合わせて1日10本近くにしない（1本ずつの表示が減るため）。
- リンク：アカウント全体で1日1回まで。使う日は日付で決める（2026-11-01 ルイ引き継ぎで確定）。奇数日（1日・3日・5日…）はルイ、偶数日（2日・4日・6日…）はレイ。自分の日でない日は、本文にも返信にもURLを入れず、「プロフィールのリンクから」で案内する。日付は日本時間で数える。
- リンクの例外（11/11 京と楓で合意）：商品単品を売る投稿ではない「ROOMコレクション・ROOM全体への誘導」に限り、商品ページ直行の専用リンクでなくROOMのURLでよい。条件はその日のリンク担当の投稿であること・1日1回の枠に数えること・1行目の頭に【PR】・伸ばす投稿のチェーン2通目に置くこと。商品名と価格を出す投稿は従来どおり専用リンクで商品ページ直行。
- 商品つきの投稿には必ず【PR】を付ける（1行目の頭）。同じ商品・同じ文面は二度出さない。
- 時間帯：レイはルイの自動投稿の前後1時間を避ける（ルイの目安：朝、12:45〜14:05、20:45〜22:05、23:43〜0:30。レイの目安：10時台、16〜18時台）。
- 話題かぶり防止：投稿したら、本文と時間を連絡ページで相手に共有する。翌日の投稿の時間と話題が決まったら、先に伝える。
- 季節・行事ネタは、出す前に日付を確かめる（本番日とずらさない）。
- 商品紹介の投稿は、PR表記を1行目の頭に付ける。
- 伸びる型：写真が主役（実写感・客寄せ・好感度）、文は短く、問いかけや二択で締める。共感型の投稿にはリンクを付けない。
- 不安をあおる言葉（凍結・稼げる・副業など）と、根拠のない不安ネタは使わない。
- 夜の商品投稿の画像（11/12 マスター指示）：マスターには画像を送らない・チェックも頼まない。流れは「京が見本を作り queue に hold を付けて push → 合図ページで楓に依頼 → 楓が画像を作る → 京か楓が検品 → 合格なら tools/apply_photo.py で入れて hold を外して push」。画像は必ず2枚で、オリジナルの女性キャラクターを使う（マスターが楓に伝えた決まり）。画像には必ずキャッチコピーを入れる（11/12 マスター指示。楓がつまずきやすい点）。楓は文字を入れない写真2枚と、キャッチコピー案1行を渡す。京が tools/apply_photo.py で【PR】・キャッチコピー・価格・商品名・AI注記を入れる（1枚目は渡されたキャッチコピーか商品の hook、2枚目は quip か推しポイント）。キャッチコピーが無いと apply_photo.py は止まる。検品の項目にも「キャッチコピーがあるか」を入れる。
