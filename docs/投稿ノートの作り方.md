# 楽天ROOM 投稿ノートの作り方（楓が代行するとき用・11/11 京）

11/11 マスター指示「何かあった時のために、楓にも投稿ノートの作り方を教えておけ」で作成。京が止まったときに楓がそのまま代わりにできる形。楓の手元の11/03版仕様書から変わった所には【変更】を付けた。

## 0. 全体
- 投稿ノート：https://claude.ai/artifact/95yfHFyYREPwhvGHra3fVA （HTMLの中の `<script id="room-data" type="application/json">` が商品データ。ほかの部分は触らない）
- 投稿済みの記録：同じページのデータ `posts`（マスターがノートから投稿すると1件ずつ増える。読むだけ）
- 更新は1日3回（6:17・11:17・16:17）。月曜朝はフル更新、それ以外は軽量更新（ランキング・在庫の確認と、足りないタブだけ補充）。
- 【変更】11/05 マスター方針：ROOMは稼ぎの柱にしない。「入口（いいね・フォロワーを育てる）とリサーチ」の道具。商品選びは「売れるか」より「いいね・保存されやすいか」を優先。
- ROOM上の操作（投稿・いいね・フォロー）は2人ともしない。マスターがアプリで行う。

## 1. 商品の選び方（タブ）
優先順：高料率（rateup）→ 詰め替え・定番（refill）→ フォロワー層に人気（fanpop）→ いいね多数（likepop）→ ROOMで人気（roompop）→ 季節・植物・ランキング各種。
- rateup：楽天アフィリエイトの料率アップ一覧 https://affiliate.rakuten.co.jp/recommend/uplist/ 。未投稿が5件未満で補充。
- refill：詰め替え・大容量・まとめ買い（定番ブランドかレビュー300件以上）。未投稿15件未満で補充。【変更】オーラルケア（歯みがき粉・マウスウォッシュ・替えブラシ・フロス）を常に3件以上（10/27 マスター指示）。
- likepop：ROOMの個別投稿ページ（room.rakuten.co.jp/<ユーザー>/<17桁>）で、いいね30以上の商品をいいね順に。毎月の「ROOM's Monthly★売れ筋セレクション」（/feature/special_hit<YYYYMM>/）を月1回必ず使う。
- roompop・fanpop：投稿ページの「この投稿を見た人におすすめ」に2回以上出る商品。fanpop はマスターが投稿したガジェットと同じ商品の投稿から。
- ランキング：楽天リアルタイム cosme 100939／kaden 562637／gadget 564500／daily 215783。1万円以下ガジェット（mini）、急上昇（buzz）。
- 除くもの：投稿済み・売り切れ・中古の新品扱い・医薬品・ふるさと納税・本・確かめられない商品。
- badges に「マスターの発見」がある商品は、投稿されるまでタブの先頭に残し文章も変えない。

## 2. いちばん大事な決まり（守らないと投稿できない・事故になる）
- itemcode は「ショップ名:数字の商品ID」。URLの後ろの文字は使わない。商品IDはレビューリンク（review.rakuten.co.jp/item/1/<ショップID>_<商品ID>）の後ろ、お気に入りの iid=、ROOMリンクの itemcode= から取る。数字が取れない商品は載せない。
- 価格・在庫・中古かは、楽天の検索結果 https://search.rakuten.co.jp/search/mall/<語>/ で「[PR]表記の無い通常の結果」から照合（2回で確かめられなければ載せない）。一度に開くのは6ページまで。
- 期限のあるセール価格は deadline に "YYYY-MM-DD HH:MM"。

## 3. 二重投稿の防ぎ方
次のどれかに当たれば投稿済みとしてどのタブにも入れない：
(a) itemcode が同じ (b) URLの item.rakuten.co.jp/<ショップ>/<商品> が同じ (c) 商品名をNFKC・小文字化して空白と記号を除いたもの（6文字以上）が同じ (d) 型番（英字で始まり数字を含む、ハイフン除き5文字以上。iphone/usb/type/bluetooth などの一般語は除く）が同じ。
posts の ng（ROOMで投稿できなかった）は (a)(b) だけで判定して除く。同じ itemcode が複数のタブにあれば refill を残す。
Threadsで出す商品とも重ねない（作戦ノート state/board.txt の「商品リスト」を見る）。

## 4. 紹介文の型（全商品に個別に書く）
- name（短く）・hook（40字以内：誰のどんな場面に合うか）・desc（1〜2文）・points（事実3つ。容量・W数・サイズ・送料無料など比べられる数字を1つ以上）
- quip（価格の横のひと言・16字以内・ツッコミ風。例「お風呂の水滴、ひと拭きで退場」）
- cap {o,s,a}【10/27から必須】：o＝つかみ35字以内、s＝推しポイント30字以内（事実を「／」で2つ）、a＝最後のひと言25字以内（すすめる・問いかける・期限を伝えるなど毎回変える。「よかったら」は全体の2割以下）。
- 使わない言葉：語尾「〜やつ」、「これだ」、「気づいたらカート」「比べてから決め」「カートのすき間」など一律の言葉、効果効能（コスメ・食品・オーラルケア・植物も）、体験談、別の商品と同じ quip・o・a。
- tags 5〜6個（#楽天ランキング #楽天ROOM は入れない）。collection は9つから1つ（下）。
- レビュー30件以上の上位商品は voice（高評価の声・35字以内）と worry（不満の声と先回りの一言・45字以内）を自分の言葉で。

## 5. コレクション付け（collection は次の9つから1つ）
「<季節名>の季節対策」「1万円以下ガジェット」「スマホ・最新ガジェット」「スキンケア・コスメ」「ヘアケア・美容家電」「キッチン・生活家電」「掃除・暮らしの便利グッズ」「買いまわり・1,000円ポッキリ」「みんなが買ってる定番」。
詰め替え・オーラルケアは「みんなが買ってる定番」か商品に合う暮らし・美容の棚。植物は「掃除・暮らしの便利グッズ」。
rate の目安：美容・食品4／日用品・キッチン・植物・オーラルケア3／家電・ガジェット2／rateup は公式の料率。

## 6. 保存の前の確認（Bash で全部確かめてから publish）
JSONが正しい／投稿済み・売り切れが無い／全商品に quip と cap があり字数と禁止語を守る／itemcode が全部「ショップ名:数字」／同じ itemcode が複数タブに無い／refill のオーラルケア3件以上。
room-data の中身だけ差し替えて同じ url に publish。競合で断られたら最新版を読み、「マスターの発見」を残して差し替え直す。publish 後にもう一度読んで確かめる。

## 7. いいねタイムとフォロー【11/08 変更】
- いいねタイムは1日4回のうち3回はガジェット系の言葉で検索してガジェット好きの投稿にいいね＋1回5人フォロー（1日15人まで）。
- フォロー先は楓が state/room_follow.json に1日10人まで足す（形は docs/rei.md「楽天ROOMの分担」）。京がノートに入れる。
- いいね総数が減り続けたら、いいねタイムだけ見直す軽量更新を1日1回まで。

## 8. 楓が代行するときの流れ
1. 合図ページに「楓が投稿ノートを代行（理由・期間）」と書く。
2. 上の1〜6で軽量更新（足りないタブだけ補充）。迷ったら商品を減らしてでも「確かめた事実だけ」を載せる。
3. 終わったら合図ページに「未投稿◯件・新しく入れた◯件・外した◯件」を1行。京が戻ったら京が引き取る。
京の定期タスク名：「楽天ROOM 売れ筋リサーチ（朝・昼・夕の3回）」（手順の本体はこのタスクの指示文。この文書はその要点）。
